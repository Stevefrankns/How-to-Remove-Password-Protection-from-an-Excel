How to Remove Password Protection from an Excel File or Sheet

If you are locked out of your own spreadsheet, removing the password depends heavily on whether it is an "open" password or a "sheet modification" password. Here is the complete, owner-safe guide to unlocking your data.

Editorial Team Updated: October 2023 8 min read
Quick Answer

To remove a password you know: Open the file, go to File > Info > Protect Workbook > Encrypt with Password. Clear the password field and save. If you forgot a sheet protection password, you can safely remove it by changing the file extension to .zip and editing the internal XML code. However, if you forgot a file "open" password, Excel's AES-256 encryption makes it impossible to remove without specialized recovery tools or backups.

The Basics

Open Password vs Permissions Password — Explained

Before trying to remove password protection from an Excel file, you must identify what kind of lock is active. Excel handles security in two fundamentally different ways:

File Open Password
Sheet/Workbook Protection

File Open Password (Encryption)

What it does: Encrypts the entire file. You cannot view any data without the password.

Security Level: High (AES-256). Very difficult to bypass if forgotten.

Removal: Easy if you know it. Nearly impossible if lost.

Sheet/Workbook Protection (Permissions)

What it does: Stops users from editing cells, hiding columns, or modifying the layout. You can still see the data.

Security Level: Low. It is a restriction rule, not true encryption.

Removal: Can be removed relatively easily using the ZIP XML method or VBA macros, even if forgotten.

Method 1

How to Remove Password Protection from Excel Files (If You Know the Password)

If you simply want to stop entering a password every time you open a document you own, you can disable the protection using Excel's built-in settings.

  1. Open the Excel file and enter the current password to gain access.
  2. Click on the File tab in the top left corner.
  3. Navigate to Info in the left sidebar.
  4. Click the Protect Workbook dropdown button.
  5. Select Encrypt with Password.
  6. A dialog box will appear showing your current password as hidden characters (dots/asterisks). Delete all the characters so the field is completely blank.
  7. Click OK.
  8. Save the file (Ctrl + S). The next time you open it, no password will be required.

Confirmation Steps

To verify it worked, close Excel completely and double-click the file to reopen it. If it opens directly to the data without a prompt, the removal was successful.

Advanced Recovery

Remove Excel Sheet Password — Without the Password

If you forgot the password that restricts editing (but can still view the file), you can remove the protection by editing the file's underlying XML structure.

The ZIP/XML Method

Because modern Excel files (.xlsx) are actually zipped archives of XML files, you can open them up and delete the specific line of code that enforces the sheet lock.

  1. Create a backup copy of your Excel file.
  2. Rename the file extension from .xlsx to .zip.
  3. Open the ZIP file and navigate to xl\worksheets\.
  4. Extract the specific sheet (e.g., sheet1.xml).
  5. Open the XML file in Notepad and find the tag <sheetProtection.../>. Delete this entire tag.
  6. Save the XML, place it back into the ZIP archive, and rename the extension back to .xlsx.
<worksheet>
  <sheetViews>...</sheetViews>
  <sheetProtection algorithmName="SHA-512" hashValue="x8H..." />
  <sheetData>...</sheetData>
</worksheet>

Using a VBA Macro

For older Excel files (.xls), you can use a Visual Basic for Applications (VBA) macro to cycle through and crack the sheet protection locally.

Press Alt + F11 to open the VBA editor, insert a new module, and run a standard unprotect macro. Note that Microsoft disabled this capability for modern AES-encrypted .xlsx files, so this only works for legacy formats.

What to Do If You Forget a Document Password (Open Password)

If you cannot even open the file, neither the ZIP method nor VBA will work. Excel uses AES-256 encryption. Your only legitimate options are restoring a previous unprotected version from cloud backups (OneDrive/Google Drive versions) or finding where you might have saved the password in a password manager.

Common Questions

Frequently Asked Questions

If you are still struggling to remove Excel password protection, check these common troubleshooting answers.

How Do I Remove Password Protection from an Excel File?
If you know the password, go to File > Info > Protect Workbook > Encrypt with Password, delete the existing password, click OK, and save the file.
How to remove password protection from an Excel sheet without the password?
You can rename the .xlsx file to .zip, open the archive, find the specific worksheet XML file, and delete the <sheetProtection> tag. Save and rename it back to .xlsx.
What is the difference between sheet protection and file password in Excel?
Sheet protection stops people from modifying cells but lets them read the data. A file password (open password) encrypts the whole document so it cannot even be viewed without the key.
How to remove a workbook password in Excel?
Go to the Review tab, click "Protect Workbook" (which will be highlighted if active). It will prompt you for the password. Enter it, and the protection will toggle off.
Can I remove Excel password protection online?
There are online services claiming to remove passwords, but uploading sensitive Excel data to an unverified third-party website is a massive security risk. We highly recommend doing it locally.
